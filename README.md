## 📖 About The Project

**VFind** is a web application engineered to bridge the communication gap between individuals who have lost items and those who have found them. Built as part of a collaborative university software engineering team project using Scrum Agile methodology, VFind offers a secure dashboard with structured workflows, administrative verification, and real-time item tracking.
